## 单篇设计文档写作模板

```markdown
# <标题> —— Maka 设计文档

## 1. 背景与目标
- 要解决的问题（从真实失败模式/需求推导）
- 对应 Maka 信条（Log is the Runtime / Context is not history /
  A task may outlive a Turn / Feedback is not fact authority）
- 关联知识点编号（KP-xx-xx）与优先级

## 2. 现状
- Maka 当前实现（包/模块/入口）
- 已有的机制（Runtime Event Log、Tool Result 剪枝、LLM Compaction、
  Self-check、budget/continuation、maka eval）

## 3. 设计要点（从书中提炼的原则）
- 原则 + 依据（书中的工程细节/数值）

## 4. 设计决策与权衡
- 决策项：选项 A vs 选项 B，取舍依据，选型

## 5. 与 Maka 四信条的映射
| 信条 | 本文档如何落地 |
|---|---|

## 6. 开放问题（引用 01-Maka-Design-Question-Checklist 对应问题）
- Q-xx：…

## 7. 验收 / 评估
- 如何评估本设计（可消融开关？回归集？model swap 归因？）

## 8. 参考
- 书中章节/实验/知识点编号
```
